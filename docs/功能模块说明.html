项目目录

Overview Module

跨项目的公司级总览看板，14列固定模板+自定义列，支持就地编辑和拖拽填充，实时多人协作。

核心功能

  • 项目一览表格（签订日期/交货日期/状态/销售/设计师/电工等）
  • 自定义列管理（增删改查+字段权限）
  • 就地编辑+向下拖拽填充
  • WebSocket实时多人协作
  • Excel全量导入（自动创建/匹配项目）
  • 导出Excel（受导出审批闸控制）

关键API端点

GET /api/overview - 一览数据
PUT /api/overview/projects/{pid}/cell - 更新单元格
POST /api/overview/import - 导入Excel
WebSocket Excel 实时协作

关键数据模型

OverviewField - 自定义列定义
OverviewFieldPermission - 字段级权限
Project.extra["__o__*"] - 一览数据存储

销售部

Sales Ledger Module

销售台账是整个ERP的"销售总账"，记录客户、合同、金额、收款、开票等全生命周期数据。

核心功能

  • 销售下单（含审批流：order_state状态机）
  • 台账查看与编辑（行级隔离）
  • 合同上传+签订日期/交货日期回写一览
  • 开票审批流（None→applying→pending_invoice→invoiced）
  • 合并开票（同客户多项目共享invoice_batch_id）
  • 订单作废（软删项目+清各部门任务）
  • 技术资料更换+修订意见处理

关键API端点

GET /api/sales/ledger - 台账列表
POST /api/sales/orders - 新建销售单
POST /api/sales/invoice-apply - 开票申请
状态机 审批流 行级隔离

关键数据模型

SalesLedger - 销售台账（1:1绑定Project）
Shipment - 发货单
RevisionRequest - 技术资料修订意见

认证模块

Authentication

用户登录/登出/改密，获取当前用户信息和菜单权限——系统入口和权限基石。

核心功能

  • 用户名密码登录（JWT token）
  • 获取当前用户信息（含role_codes多角色并集）
  • 获取菜单权限（/menus端点驱动侧边栏）
  • 修改密码（校验旧密码+不等于新密码）
  • 登出（客户端清token）

关键API端点

POST /api/auth/login - 登录
GET /api/auth/me - 当前用户
GET /api/auth/menus - 菜单权限
POST /api/auth/change-password - 改密码
JWT 菜单权限 多角色

WebSocket协作

Real-time Collaboration

基于WebSocket的实时广播，用于多用户协作编辑时的单元格变更通知和在线状态感知。

核心功能

  • 数据表房间（ws://.../ws/datasheets/{did}）
  • 总览房间（ws://.../ws/overview）
  • 单元格变更广播（broadcast_cell_changed）
  • 在线状态感知（presence.join/leave）
  • keepalive（ping/pong）

关键API端点

WS /ws/datasheets/{did} - 数据表协作
WS /ws/overview - 总览协作
实时协作 房间管理 在线状态

附件管理

Attachments

全系统所有业务文件的统一上传、下载、打包、删除——被所有业务模块复用的底层服务。

核心功能

  • 文件上传（16种业务类型+扩展名白名单）
  • 单文件下载
  • 打包下载（ZIP流式返回）
  • 删除（仅上传者本人或admin/manager）
  • 辅助函数供其他路由复用（save_upload/copy_attachment/delete_attachment_file）

关键API端点

POST /api/attachments - 上传文件
GET /api/attachments/{aid}/download - 下载
POST /api/attachments/package - 打包下载
DELETE /api/attachments/{aid} - 删除
文件管理 ZIP打包 权限控制
