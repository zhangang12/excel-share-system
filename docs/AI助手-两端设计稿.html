两个端各做什么

端范围说明
电脑端系统里的一个页面与其它业务页并列，查询结果用完整表格，可跳去业务页核对
H5 端登录 + 助手框独立入口，进去就是对话。不做业务页面——手机上填单子是灾难，看数和批单很合适
H5 的定位：老板在外面想看一眼数、批一下单。所以它不是「把系统缩小」， 是只保留能在手机上做好的那两件事。

登录绕不开的一道闸

H5 必然要走外网登录闸门。

gate.py 的规则是：浏览器 + 外网 IP + 非 admin 登录时，要再输 6 位验证码。 免闸的只有桌面客户端（靠 X-PMS-Client 请求头）、admin、内网 IP。

H5 是浏览器、在外面用必然是外网，所以每次登录都要两步。而验证码发给 manager 角色池， 池子里就是杨坛和赵仁辉本人——他输密码，企微收到自己的码，再输进去。

能用，但多一步。要不要给 H5 开免闸口子是安全与便利的取舍，得你定（见文末「要你决定的事」）。

要你决定的事

H5 相关

  1. H5 要不要免闸？三个选择：① 保持两步（最安全，每次多一步）； ② 设备记住（首次两步，之后 N 天免）； ③ 完全免闸（不建议——H5 就是给外网用的，闸门正是为这个场景设的）。
  2. 从哪进？企微工作台挂应用最省事（已经在用企微推送），还是给独立网址自己存书签？
  3. 手机上要不要能驳回？驳回要填原因，手机打字麻烦。可以只给「通过」，驳回引导回电脑端。
  4. 深色模式跟随系统？稿子里已经画了，做的话工作量不大，但要多测一轮。
